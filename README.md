# GodCheck 无敌检测

- 作者: 羽学
- 出处: 无
- 这是一个Tshock服务器插件，主要用于：对玩家无敌检查并处罚。

## 更新日志

```
v2.0.2
加入了十字项链的窗口期动态无敌帧过滤
预计碰撞伤害包含免伤率与浮动计算

v2.0.1
增加恶意刷无敌帧检测
减少对无敌处理误判率

v2.0.0
重构代码，使用实体碰撞箱来检测玩家是否无敌
加入指令/pun 用于添加或移除惩罚名单玩家
免检无敌权限更名为：pun.use(同时也是指令权限)
```

## 指令

| 语法                             |          权限         |                   说明                   |
| -------------------------------- | :------------------:  | :--------------------------------------: |
| /pun                             |  pun.use              |               惩罚名单修改               |
| /reload                          |  tshock.cfg.reload    |               重载配置文件               |

## 配置
> 配置文件位置：tshock/无敌检测.json
```json
{
  "插件开关": true,
  "违规提醒": true,
  "检测冷却": 1,
  "违规次数": 3,
  "自动踢出": false,
  "每秒受伤": 4,
  "惩罚名单": [
    "羽学"
  ]
}
```
